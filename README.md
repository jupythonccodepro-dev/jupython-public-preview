# Aperçu public Jupython

Cette page statique autonome est conçue pour une prévisualisation publique. Elle ne contient ni le backend Django, ni la base de données locale, ni les comptes utilisateurs, ni les secrets du projet.

Le contenu se limite aux informations confirmées : Jupython est une plateforme congolaise francophone proposant des cours gratuits en informatique. La page précise que la plateforme est en cours de développement.

Pour publier gratuitement sur Render, créer un dépôt Git public contenant uniquement le contenu de ce dossier, puis choisir **New → Static Site** et suivre le déploiement. Render fournit une URL publique en `onrender.com`. La page peut ensuite être mise à jour en poussant les modifications du dépôt.

La publication nécessite un compte Render et un dépôt Git hébergé. Ne pas pousser le dépôt principal entier pour cette prévisualisation.
